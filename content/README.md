# Seed content

This directory is tracked by git and the repository is public on GitHub, so every file here (and every past version of it) is published.
Only public knowledge belongs here: textbooks, published papers, public datasets, languages, geography.
Unpublished research (data, results, manuscripts, the design of unpublished projects), information about people, internal project or funding details and anything written from private sources go into a private file outside this repo (convention: `~/projects/<project>/pauk-cards/`) and are imported from there.
See "This repository is PUBLIC" in `../CLAUDE.md`; when in doubt, keep it out and ask.

Importable content files, one JSON per topic:

- `greek.json` — 72 cards: name the Greek letter, as
  lowercase/uppercase free text and multiple choice with
  confusable distractors. Generated by `generate_greek.py`
  (deterministic; edit the script, re-run, commit both).

- `italian.json` — 209 cards toward Italian A1: core and
  common verbs, nouns (accepted with and without article),
  adjectives, numbers, survival phrases, and grammar
  multiple choice. The `italian/a1` directory bundles all
  topic directories via extra DAG links.

- `phd-*.json` — six PhD-defense decks (adadmire, FastRet,
  immune system, liquid chromatography, metabodecon, NMR),
  mostly self-graded recall cards with a few mc/text checks,
  all under the `phd` directory.

- `items-*.json` — knowledge items (docs/tutor.md, docs/api.md "Knowledge profile") with links from every card of the matching decks, so answering a card is evidence for its items.
  Import them after their decks.
  `items-greek.json` (24 letters, space `el`) and `items-italian.json` (vocabulary, grammar rules, irregular present paradigms, space `it`) are generated by `generate_items.py` from the decks (deterministic; edit the script, re-run, commit both).
  `items-phd.json` holds the key concepts of the PhD decks in space `concepts`, linked into the deck directories and the subjects `bioinformatics` and `immunology`.
  `items-germany.json` (states and cities, space `concepts`) and `items-italian-town.json` (town words, space `it`) hold the items the activities below refer to; both are hand-written.

- `items-bio-*.json` and `items-med-*.json` — bioinformatics and clinical knowledge for work at a university hospital, space `concepts`, all under `bioinformatics/`: cancer genes and their proteins (`items-bio-cancer-genes.json`), immune, transplant, liver and pancreas genes and proteins (`items-bio-immune-liver-genes.json`), measurement technologies for bulk, single-cell and spatial expression and proteomics (`items-bio-technologies.json`), liver disease and transplantation (`items-med-liver-transplant.json`), cancer and PDAC (`items-med-cancer-pdac.json`).
  Written by LLM agents from a shared spec (one item per gene, protein, technology, disease, score or treatment; `priority` says how essential it is; memory aids where good ones exist), cross-checked for duplicates; keys: `gene-<hgnc symbol>`, `protein-<name>`, otherwise a slug of the English term.
  Some link into `items-phd.json` or each other, so import them after it (`cli/tests/test_content.py` imports all item files in link order).

- `comit-tp6-*.json` and `items-comit-tp6-*.json` — PDAC background for CoMIT TP6, space `concepts`, all under `comit/tp6/`: biology (pancreas cells, immune attack and resistance, RNAi screens), statistics (expression data, tumour purity, survival analysis, prognostic models, validation), literature (who published which paper, model and subtype scheme) and datasets (cohorts, accessions, portals).
  Decks and items come in pairs; the items link to the existing `bioinformatics/` items instead of repeating them, and the statistics and datasets items link to the literature items, so `items-comit-tp6-literature.json` is imported first.
  Only published knowledge is here; anything about the project's own work lives in a private file outside this repo.

- `curricula/` — courses for the tutor's level map (docs/tutor.md 9.6): `italian.json` (A1 from the existing Italian items, A2 from `items-italian-a2.json`, B1–C2 as units the teacher fills) and `bioinformatics.json` (stages cancer and PDAC, cancer genes, liver and transplantation, immune/liver/pancreas genes, technologies; each unit ordered by importance).
  `comit-tp6.json` (course "CoMIT TP6 (PDAC)": stages essentials, biology, statistics, papers and models, datasets) uses the `items-comit-tp6-*.json` items plus a few existing PDAC items.
  `pauk import content/curricula/italian.json` creates one directory per unit under `italian/course/` and links the listed items; import the items files first.
  The CLI ships a copy in `cli/pauk/data/curricula/` (`cli/tests/test_curriculum.py` checks that both are equal and that every listed item exists).

- Memory aids: items may carry `attrs.mnemonic` (an Eselsbrücke, "(de)" marks a German one) and `attrs.anecdote` (a true, memorable story); `attrs.aliases` lists other names and becomes searchable aliases on import.
  For the generated files they live in the `MEMORY` table of `generate_items.py`.

- `activities/` — tutor activity content (docs/tutor.md 14): `germany-states.json`, `germany-cities.json` (map labelling), `italian-town.json` (town scene, the successor of `italian-quests.json`), and `maps/germany.json`, the blank base map exported by `scripts/maps/export_activity_map.py`.
  These are not imported; the CLI ships a copy in `cli/pauk/data/activities/`, so after editing a file here copy it there (`cli/tests/test_activities.py` checks that both are equal and that every ref names an item of an `items-*.json` file).
  Texts shown to the learner (`prompt_md`, a town object's `hint`, a goal's `task_md`) are a string or translations like `{"en": "...", "de": "..."}`; the browser picks the learner's UI language.

  Item file format:

      {"space": "it", "dirs": ["italian/grammar"],
       "items": [{"key": "present-are", "kind": "rule", "label_md": "...", "gloss_md": "...",
                  "dirs": ["italian/grammar"], "links": [{"rel": "requires", "to": "noun-gender"}]}],
       "card_links": [{"card": "<exact question_md>", "item": "present-are"}]}

  Re-importing updates items in place (identity is `space/key`).

Directory names must match `^[a-z0-9-]+$` (docs/api.md), so
keep paths lowercase (`phd/nmr`, not `PhD/NMR`). The e2e suite
imports every file here (`cli/tests/test_content.py`).

Import format (see docs/api.md for card shapes):

    {
      "dirs": ["path", "path/sub", ...],
      "dir_links": [{"parent": "p", "child": "c"}, ...],
      "cards": [{"dirs": ["path/sub"], "type": "text", ...}]
    }

Import with `pauk import content/<file>.json`. Imports are
idempotent: existing dirs are reused and cards whose
question_md already exists are skipped, so re-importing after
adding new cards to a file only creates the additions.
