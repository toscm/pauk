# Do we need tags in addition to directories?

An earlier draft had a separate tag system. It was dropped
when directories became multi-membership DAG collections: a
flat directory ("hard", "exam-2027") does everything a tag
did, including cross-cutting groupings, and one organizing
concept keeps API, CLI, and UI simpler.

Reopen if practice shows a real need tags would cover better
(e.g. wanting card metadata that should not appear in the
directory tree).

2026-10-14: Closed as decided above: no tags.
Subjects (directories, now holding items as well as cards) cover the cross-cutting groupings.
